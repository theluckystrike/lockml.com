ML Security Tools

Free browser-based tools for securing machine learning systems. Threat modeling, security audits, robustness testing, and privacy budget tracking.

ML Threat Model Generator

Generate comprehensive threat models using STRIDE framework adapted for ML. Covers model impersonation, adversarial inputs, audit trails, and extraction attacks.

ML Model Security Audit

Generate tailored security audit checklists. Select your model type and get 20+ items covering data poisoning, extraction, adversarial robustness, and access control.

Model Robustness Scorer

Evaluate ML model resilience against Gaussian noise, adversarial inputs, feature dropout, and distribution shifts with defense recommendations.

Privacy Budget Calculator

Track differential privacy budget consumption across queries. Calculate cumulative epsilon under sequential and parallel composition with budget allocation.
