How Membership Inference Works

A membership inference attack tests whether a model leaks information about its training data. An attacker with access to a model's confidence scores can distinguish between data points that were in the training set and those that weren't.

Key Metrics:

  • Attack Accuracy: Overall correctness of the attacker's membership predictions
  • Precision: Of predicted members, how many were actually in training set
  • Recall (TPR): Of actual training members, how many the attacker identified
  • False Positive Rate: Percentage of non-members incorrectly classified as members
  • F1 Score: Balanced measure of precision and recall
  • AUC Score: Overall attack effectiveness across all thresholds (0.5 = random, 1.0 = perfect attack)

Risk Levels:

  • Low (AUC < 0.6): Model does not leak membership information
  • Medium (0.6 ≤ AUC < 0.75): Some privacy leakage detected, consider mitigation
  • High (0.75 ≤ AUC < 0.9): Significant privacy risk, implement defenses
  • Critical (AUC ≥ 0.9): Severe privacy leakage, urgent action required

Defenses:

  • Differential Privacy: Add noise to training process
  • Model Regularization: Use L1/L2 regularization to prevent overfitting
  • Ensemble Methods: Combine multiple models with different random seeds
  • Gradient Clipping: Limit gradient magnitudes during training
  • Label Smoothing: Reduce confidence on training data labels
